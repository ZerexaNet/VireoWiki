      MCP 客户端 JSON 请求头示例
      MCP 클라이언트 설정 파일(mcpServers)의 Authorization 헤더에 API 密钥를 Bearer <YOUR_API_KEY> 형식으로 지정하세요. 
      {
  "mcpServers": {
    "cloudwiki": {
      "url": "https://cloudwiki.domain/api/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}
