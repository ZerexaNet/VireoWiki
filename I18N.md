# Interface languages

VireoWiki supports Simplified Chinese (`zh-CN`, default) and English (`en`). The language selector keeps the current URL and stores `vireo_locale` for one year. A valid `?lang=` overrides the cookie; `DEFAULT_LOCALE` in Wrangler sets the fallback. Article text, slugs, markup grammar, status codes and user content stay unchanged.

## Adding interface text

Catalogs live in `packages/wiki-shared/src/i18n/`: `source.json` records the original authored message; `zh-CN.json` and `en.json` contain the same keys. `sources.json` records original locations for migration reference. Use a descriptive new key or `m_` plus the first 16 hexadecimal characters of the source message's SHA-256. Add all three catalog values together.

In browser modules import `ui` from `packages/wiki-shared/src/i18n/client`; server modules use `src/i18n/server`. The latter keeps the locale isolated with AsyncLocalStorage, so concurrent requests cannot share a language. Shared server helpers accept a locale explicitly. Classic extensions use `window.VireoI18n.ui` after the page bootstrap.

`ui(key, [value0, value1])` fills `__VIREO_SLOT_0__`, `__VIREO_SLOT_1__`, etc. Keep existing escaping at the interpolation call site. Do not translate input text, namespace prefixes, SQL, CSS classes, API identifiers or parser tokens. Translations may reorder slots, but must preserve every slot exactly once for each original occurrence. HTML templates must preserve markup and behavior attributes; only visible text and accessibility labels change.

## Static pages and checks

Astro creates the original shells. `scripts/localize-shells.mjs` writes both languages to `public/_i18n/{locale}`. Worker routes select the correct shell; direct static HTML uses the default Chinese output. The language bootstrap is a Vite entry at `/dist/i18n.js`, included in every shell. Adding an authored static label also requires cataloging its original text. `<code>`, `<pre>`, scripts and `data-no-i18n` content are protected.

Run `npm run test:i18n`, `npm run typecheck`, `npm run typecheck:client` and `npm run build`. CI checks catalog coverage, slots, HTML structure, language negotiation and concurrent request isolation. No translation service is used at runtime. Main-branch pushes deploy the existing `vireowiki` Worker using `wrangler.production.toml`; credentials remain Cloudflare secrets.
